# Specialist: Frontend Next.js

## Rules
- Server Components by default
- `use client` only with justification comment
- shadcn/ui — don't reinvent UI
- Forms: react-hook-form + Zod
- Always handle loading and error states
- Component > 150 lines → break it up
- Props typed with interface

## Code style
- English: variables, functions, files, comments
- Indentation: 2 spaces
- Functions: max 20 lines

## KISS
Before creating a custom component, check if shadcn has it.
